⚡ Loki v3.0 · Переглядач лог-файлів
📂 Відкриття файлів
Ctrl+O або кнопка Відкрити — відкрити файл
Drag & Drop — перетягни файл прямо у вікно
▾ поруч з "Відкрити" — нещодавні файли (до 10 штук)
+ у вкладках — відкрити у новій вкладці
Формати: .log .txt .gz .zip
ZIP з кількома файлами — з'явиться список для вибору
🔄 Live mode
При відкритті .log / .txt — Live ON вмикається автоматично
Polling кожні 800 мс — надійно працює навіть якщо сервер тримає файл відкритим
Читає тільки нові байти — швидко навіть для файлів >100 МБ
Авто-скрол вниз якщо ти був внизу списку
Ротація / truncate файлу — автоматично перезавантажує весь вміст
Клік ⟳ Live — вмикти / вимкнути вручну
🔍 Пошук і фільтрація
Поле пошуку — простий текст або /regex/i
F3 / Shift+F3 — наступний / попередній збіг
Лічильник N збігів · pos/N — показує позицію у результатах
INFO / ERROR / WARN — клік = соло-режим, повторний = всі
⊘ Виключити — прибрати рядки що містять певний текст (через кому кілька)
Виключення зберігаються між сесіями
🖱️ Виділення рядків
Клік — відкрити деталі рядка в правій панелі
Ctrl+клік — мульти-вибір рядків
Shift+клік — виділити діапазон від попереднього кліку
👁 Тільки ці — залишити у списку тільки виділені рядки
💾 Зберегти .txt — експортувати виділені в текстовий файл
↑ / ↓ — навігація між рядками
🔖 Закладки
B — поставити / зняти закладку (EN, UA, RU розкладка — однакова фізична клавіша)
F2 / Shift+F2 — наступна / попередня закладка
Рядки з закладкою підсвічуються у списку
🟡 Trace — підсвітка запиту
Клік по trace (#abc…) — підсвітити всі рядки того ж запиту жовтим
Повторний клік по trace або ✕ у trace-bar — скинути підсвітку
Escape — скинути trace або виділення рядків
📌 Права панель — JSON деталі
Клік по рядку — розгортає повний JSON з синтаксичною підсвіткою
Пошук у body — підсвічує збіги прямо у JSON-дереві
⊞ / ⊟ — розгорнути / згорнути всі вузли JSON одним кліком
⌫ {} — копіювати тільки JSON body  |  Ctrl+Shift+C
⌫ ¶ — копіювати повний рядок логу як є
Панель можна приховати кнопкою ▶ / розгорнути ◀
⭐ Збережені & Порівняння
☆ — зберегти поточний рядок; ★ — вже збережено
Збережені з'являються у панелі ★ N — перегляд по вкладках
Збережи 2+ записи → кнопка ⟺ Порівняти — diff двох JSON body
Зручно порівнювати запит і відповідь або два різних запити
Порівняння відкривається в окремому вікні
⚙️ Відображення
W або ⇔ — wrap mode: динамічна висота рядків (повний текст без обрізки)
A− / A+ — розмір шрифту 9–20 px (впливає і на список, і на JSON-панель)
🔓 / 🔒 — заблокувати ширину колонок від випадкового зсуву
Колонки тягнуться за заголовок; ⊟ → ↺ Скинути ширини — повернути дефолт
⊟ — сховати/показати окремі колонки (Час, Рівень, Trace, Comp, Dir)
Ширина правої/лівої панелей тягнеться за розділювач посередині
🗂️ Вкладки
+ — відкрити файл у новій вкладці
Кожна вкладка зберігає: файл, скрол, виділений рядок, live-стан, закладки
× на вкладці — закрити (остання вкладка просто скидається)
⌨️ Всі гарячі клавіші
Ctrl+O — відкрити файл
F3 / Shift+F3 — наступний / попередній збіг пошуку
↑ / ↓ — навігація між рядками
B — закладка  |  F2 / Shift+F2 — між закладками
W — wrap mode  |  Ctrl+Shift+C — копіювати JSON body
Escape — скинути trace / виділення  |  F1 — ця довідка
Всі налаштування зберігаються автоматично між сесіями
